## 開催趣旨

本研究会は、宇宙初期の天体形成と進化に関する研究の現状を総括し、今後の課題について幅広く議論することを目的として、約20年にわたり毎年開催しているものです。

研究会で扱う話題は、初代星・初代銀河を中心に、

- 初代星および低金属量星の形成と進化
- 初代銀河と高赤方偏移銀河
- 宇宙再電離
- 巨大ブラックホールの起源と成長
- 高赤方偏移のAGNおよびLittle Red Dots
- 高赤方偏移突発天体
- 星団形成、ハブ・フィラメント構造
- 銀河考古学および重力波源

など、研究の進展とともに広がっています。

例年は50～60名程度が現地参加する国内研究会ですが、今年度は海外からも招待講演者を迎え、国際的な交流を少しずつ広げることを目指します。講演は原則として英語を予定していますが、一部の学生講演については日本語での発表も可能とする予定です。

この分野に関心のある方や、これから研究を始めたい学生・若手研究者の参加も歓迎します。皆様の積極的なご参加をお待ちしています。
